Yabgu

Short instruction files + a local MCP so coding agents are more accurate — without switching models. Your repo never leaves your machine.

Kısa talimat dosyaları; model değişmez, proje yerelde kalır.

Install MCP View on GitHub

Add in ≈60 seconds

Paste a config, or write it from the terminal. No chicken-egg — you do not need MCP already connected.

Cursor

Create .cursor/mcp.json (or ~/.cursor/mcp.json):

{
  "mcpServers": {
    "yabgu": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "@emrahyasinisik/yabgu", "mcp"]
    }
  }
}

or

npx @emrahyasinisik/yabgu setup cursor --write

Claude Code

claude mcp add --transport stdio yabgu -- npx -y @emrahyasinisik/yabgu mcp

Codex, Copilot, Gemini, Grok, … → docs/hosts.md or yabgu setup <host>.

Scan → plan → approve → apply

Local stdio only. Writes instruction paths after you approve — not arbitrary source.

What this is / is not

  • Instruction / host-setup standard
  • Catalog + templates for Cursor, Claude, Codex, Copilot, Gemini, Grok…
  • Local MCP: scan, plan, apply, measure, conflicts, forge
  • Not a model picker or Auto router
  • Does not control how the agent speaks
  • Does not sell measure score as invoice proof
