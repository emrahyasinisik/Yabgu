# acme-dashboard

Example **consumer** app used to exercise Yabgu for real (not the kit’s unit tests).

React 19 UI (Vite) and an Express 5 API share `src/`. Package manager is **npm**. This tree intentionally starts **without** `AGENTS.md` / adapters so you can measure before → apply → measure after.

See [../README.md](../README.md) for the protocol.
